## 🚀 Installation

1. **Télécharge** tous les fichiers dans un même dossier
2. **Ouvre** `index.html` dans ton navigateur
3. **Pour le formulaire** : remplace l'email dans `contact.html` par le tien (`habonemahdi0@gmail.com`)
4. **Pour la photo** : mets ton image de fond dans le dossier `assets/images/`
